# DeviNet – Guessing Game | Jeu de devinettes

Final project – **420-DW3-AS Web Server Application Development 1** – Collège LaSalle
Author: **Adja Fatou CISS**

DeviNet is a PHP / MySQL web application where a registered user tries to guess
5 distinct numbers (from 0 to 12) generated randomly by the server, using a
drag and drop interface.

---

## 1. Requirements

- PHP **8.0 or higher** (uses the `match` expression and constructor property promotion)
- MySQL or MariaDB
- A local server such as **XAMPP**, WAMP or MAMP
- PHP extension `pdo_mysql` (enabled by default in XAMPP)

## 2. Installation

1. Copy the folder `devinet-jeu-game` into the web root
   (WampServer: `C:\wamp64\www\` – XAMPP: `C:\xampp\htdocs\`).
2. Start WampServer (green icon) or Apache + MySQL in the XAMPP Control Panel.
3. If your MySQL user/password/port are not `root` / *(empty)* / `3306`,
   edit `config/config.php`.
4. Open <http://localhost/devinet-jeu-game/> in a browser.

The database `jeu_devinette`, the table `compte_utilisateur` and the 3 test
accounts are **created automatically** the first time the application is accessed.
No SQL script needs to be imported manually.

## 4. How to use

1. **Sign up** (registration form) or **log in** with a test account.
2. In the game form, drag and drop 5 numbers into the 5 boxes
   (you can also click a number to place it, and click it again to remove it).
3. Click **PLAY**: the generated numbers, your numbers, the result and the
   feedback are displayed, and the score is updated.
4. Click **LOG OUT** to end the session.

### Score
`points won / possible points` – each game adds 1 point per number guessed
and 5 possible points. Example: 2/5 → 6/10 → 6/15.

### Test mode (to demonstrate scenario 1)
Guessing all 5 numbers happens about once in 1287 games. To demonstrate it,
set `GAME_TEST_MODE = true` in `config/config.php`: the game will then always
"generate" `1, 0, 3, 2, 4`. **Set it back to `false` afterwards.**

## 6. Technical choices

- **Separation front-end / back-end**: every form has its own display page and
  its own handling page. Handling pages never display HTML: they validate,
  save messages in the session and redirect (Post/Redirect/Get pattern), so
  every message is displayed inside a front-end page.
- **Functions and classes**: repeated HTML (header, footer, messages, input rows)
  is generated by functions in `includes/functions.php`; the database and game
  logic are in classes.
- **try / catch**: every MySQL operation is inside a `try/catch`. A
  `PDOException` is converted into a `DatabaseException` with a clear message
  displayed in the page (e.g. when MySQL is stopped).
- **Security**: prepared statements (no SQL injection), `password_hash()` /
  `password_verify()`, `htmlspecialchars()` on every displayed value (no XSS),
  `session_regenerate_id()` at login, POST for every action.
- **Exact login**: the username must be identical, including upper/lower case.
- **PHP components not practiced in class**: `match` expression
  (`GuessingGame.php`, `game-form.php`), constructor property promotion,
  union types (`string|int`), `mixed` type, heredoc syntax.

## 7. Known limitations / troubleshooting

- *"Unable to connect to the database"*: MySQL is not started, or the settings
  in `config/config.php` are wrong (MAMP uses port 8889 and password `root`).
- The score is kept in the session: it restarts at 0/0 after each login.
- The live clock uses the time of the visitor's computer; the first value
  displayed comes from the server (time zone America/Toronto).
